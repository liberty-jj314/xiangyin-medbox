# 密钥填写说明

本仓库**不包含任何云服务密钥**。这是有意的：密钥一旦公开，别人可以直接消耗你的额度，
而且 Git 历史会永久保留——事后删除文件也没用。

要跑起来，你需要自己申请 4 把密钥，放进 `01_资料/` 下 4 个 txt 文件里。

> ⚠️ 这四个文件已在 `.gitignore` 里排除，**不会被提交**。创建后不要 `git add -f`。

---

## 为什么需要 4 把

| 文件 | 用在哪 | 不填的后果 |
|---|---|---|
| `百度智能云密钥.txt` | 拍照认药（OCR） | **服务直接拒绝启动** |
| `阿里云百炼密钥.txt` | 问药（大模型）+ 语音识别（Fun-ASR） | 问药功能不可用 |
| `百度语音识别密钥.txt` | 备用语音识别 | 只在切到"百度识别"时需要 |
| `高德地图密钥.txt` | 后台的地区问药地图 | 地图退化为方块占位，不影响问药 |

---

## 文件格式

每个文件都是「**标签: 值**」，一行一个：

### `01_资料/百度智能云密钥.txt`

```
API Key: 你的24位APIKey
Secret Key: 你的32位SecretKey
```

> 在 [百度智能云控制台](https://console.bce.baidu.com/ai/) → 文字识别 → 创建应用，
> 免费额度足够演示（通用文字识别每月有赠送次数）。

### `01_资料/阿里云百炼密钥.txt`

```
API key: sk-你的百炼APIKey
模型名称: qwen-plus
```

> 在 [阿里云百炼](https://bailian.console.aliyun.com/) → API-KEY 管理 里创建。
> 一次 20 题的模型调用实测花费约 0.11 元。

### `01_资料/百度语音识别密钥.txt`

```
API Key: 你的24位APIKey
Secret Key: 你的32位SecretKey
```

> 注意：这是「语音技术」的应用，和 OCR 那套是**两个不同的应用**，密钥不通用。

### `01_资料/高德地图密钥.txt`

```
API Key: 你的高德Web端Key
安全密钥: 你的32位安全密钥
```

> 在 [高德开放平台](https://console.amap.com/) → 应用管理 → 添加 Key（服务平台选「Web端(JS API)」）。

---

## 没有密钥也想看看效果？

服务启动时会先检查密钥，缺失就直接打印 `【停】找不到密钥文件` 并退出——
这是**故意的**：宁可起不来，也不要带着空配置跑起来给老人错误的药量。

如果只是想看界面和交互，可以先只填 `百度智能云密钥.txt`（它决定服务能否启动），
其余功能会在调用时报错，但页面本身可以打开。

## 安全提醒

- 这四个文件**不要**发到任何公开仓库、群聊、截图里
- 如果曾经误传过，去对应控制台**重置密钥**，而不是只删文件
- 本项目的 `server.py` 只在服务进程内存里保存密钥，前端（F12）拿不到任何一个
